## Descripción del Proyecto

El sistema Gestión de Citas Médicas es una aplicación web diseñada para facilitar la administración de citas médicas en clínicas locales de San Salvador, El Salvador, donde el sistema permitirá:
- Registro de pacientes
- Registro de médicos
- Programación de citas médicas
- Gestión de historial médico
- Evaluación del servicio médico
El objetivo es mejorar la organización del servicio médico y optimizar los procesos administrativos de la clínica.
